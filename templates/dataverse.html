            URGE (USN Readme File Generator) is a comprehensive tool designed to create detailed and standardized README files for datasets in accordance with the FAIR principles (Findable, Accessible, Interoperable, and Reusable).
            

                                            
            Key features:
            
                                            
              
                                                
            • Multiple import options: Import from DMP (SIKT DMP, DSW ELIXIR - NO), existing README files, or Dataverse
              • 
                                                
            • Smart metadata handling: Automatically fetch and populate metadata from Dataverse
              • 
                                                
            • Grammar checking: Built-in grammar checker to ensure high-quality documentation
              • 
                                                
            • Flexible export: Generate both standard and anonymous README files
              • 
                                                
            • JSON support: Export metadata in JSON format for machine readability
              • 
                                                
            • Interactive interface: User-friendly form with tooltips and helpful guidance
              • 
                                            
            

                                            
            Benefits:
            
                                            
              
                                                
            • Ensures consistency in dataset documentation
              • 
                                                
            • Facilitates data sharing and reuse
              • 
                                                
            • Supports compliance with data management standards
              • 
                                                
            • Enhances dataset discoverability and citation
              • 
                                            
            

                                            
            URGE is an essential tool for researchers, data managers, and institutions committed to maintaining high standards of data documentation and sharing in the scientific community.
            
                                            
            URGE does not store any data entered in this form in a database; it is used only for the duration of your request.

                                                    Figshare token safety

                                                        After generating your README, revoke or regenerate the token from your Figshare account settings if you no longer need it here.
                                                    
            
                                                
            
                                            
            
                                            
            
                                                
                                                
                                                
                                                
                                                
                                                
            
                                                    Zenodo token safety
                                                    
            
                                                        Your Zenodo personal access token is yours alone and is never stored on the URGE server.
                                                        Create a token with at least deposit:read (and deposit:write if required by your account) from Zenodo account settings.
                                                        After generating your README, revoke the token if you no longer need it here.
